# UniversalHelper

Учебный консольный проект на C# с примерами перегрузки методов и вспомогательных классов: вычисления, строки, даты, массивы, сотрудники, доставка и другие задачи.

## Требования

.NET SDK 8.0 или новее с поддержкой целевой платформы .NET 8.

## Запуск

```sh
dotnet run --project UniversalHelper.csproj
```

## Сборка

```sh
dotnet build UniversalHelper.csproj
```

Исходный код находится в `Program.cs`. В `Main` показаны примеры использования класса `Helper`. Примеры авторизации в `Auth` содержат учебные значения.
